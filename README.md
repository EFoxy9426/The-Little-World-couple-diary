# 小小世界 · 情侣生活记录网站

> 两个人的私密数字回忆本：在一起的天数、点滴时光轴、愿望清单、悄悄话。

## 怎么运行（Phase A 单机原型）

- 方式一：直接双击打开 `index.html`（推荐 Chrome / Edge）
- 方式二：在项目目录起个本地服务再打开
  - python: `python -m http.server 8080` 然后访问 http://localhost:8080

无需安装任何依赖，数据保存在当前浏览器的 localStorage 里。

## 功能

- 🏠 我们的日子：在一起第几天、纪念日倒计时
- 📖 点滴时光轴：带日期 / 心情 / 照片的记录，可点赞评论
- 🎯 愿望清单：许愿日期 + 完成日期 + 放弃状态
- 💌 悄悄话：带日期与时分的小纸条，可回复
- ⚙️ 设置：两个人的称呼与头像、在一起日期、纪念日、导出 / 导入备份

## 默认设定（可在设置里改）

- 网站名：小小世界
- 小弟（男生）🐶 × 大哥（女生）🐱
- 在一起的日子：2025-12-25

## 数据与隐私

- 原型阶段：数据只存本机浏览器，**请定期「设置 → 导出备份」**，把 .json 存到网盘 / 电脑。
- 正式版计划：双人账号 + 邀请码绑定 + 云端数据库，多端同步，完全私密。
